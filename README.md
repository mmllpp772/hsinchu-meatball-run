## 2. 影片概念

新竹三寶「米粉、貢丸、肉圓」大家都聽過，但**到底哪一家的貢丸湯配米粉最好吃？** 我們一天之內把六家名店吃一輪，從必比登推介、百年老店到排隊老攤，現場評分，最後選出冠軍。

**「路跑」包裝：**
- 開場：別上號碼布、熱身操、鳴槍起跑（其實是走去開車 😂）
- 每家店 = 一個「補給站」，畫面上跳出「第 X 站／剩下 X 站」
- 計步器記錄一天走了幾步，跟吃下的貢丸數對比
- 結尾：頒發自製「貢丸完賽獎牌」，公布「冠軍補給站」

**觀眾得到什麼：**
- 一份可以直接照著走的新竹貢丸米粉一日路線
- 每家店的特色、價格與真實評分
- 輕鬆好笑的「吃到撐」挑戰感

## 3. 六家店家名單

| # | 店家 | 地點 | 為什麼選它 | 必點 |
|---|---|---|---|---|
| 1 | **一哥炊粉** | 新竹縣芎林鄉福昌街 621 號 | 2026 米其林必比登新入選，40 年以上客家老店 | 炊粉（乾炒 / 湯）、貢丸湯 |
| 2 | **石家魚丸** | 新竹市東區興學街 | 在地 80 年老店，手工丸、假日大排長龍 | 貢丸湯、魚丸湯 |
| 3 | **海瑞摃丸**（西門街總店） | 新竹市北區西門街 98 號 | 1948 年創立的貢丸老字號，口味多達 20 多種（和牛、松露…） | 原味摃丸、創意口味試吃 |
| 4 | **阿城號米粉** | 新竹市北區中山路 75 號（城隍廟內） | 城隍廟 80 年以上老攤，手工米粉淋碎肉滷汁 | 炒米粉、貢丸湯 |
| 5 | **柳家肉燥飯** | 新竹城隍廟前廣場 | 在地人「炒米粉 + 貢丸湯」的經典組合 | 炒米粉、貢丸湯 |
| 6 | **東門米粉攤** | 東門市場 1158 號 | 新竹市米其林必比登推介，粗米粉 + 入口即化芋頭 | 芋頭米粉湯 |

### 店家亮點（給旁白 / 字卡用）

**① 一哥炊粉｜必比登新貴**
- 「炊粉」是用在來米蒸（炊）出來的細米粉，跟一般新竹米粉做法不同，正好拿來開場講「新竹米粉不只一種」
- 米其林評語提到貢丸湯有肉香和蘿蔔的清甜
- 客家傳統早餐店 → 適合當**第一站（早餐）**

**② 石家魚丸｜80 年手工丸**
- 一邊是用餐區、一邊是丸子工廠，**可以拍製丸過程**（需先徵求同意）
- 早上 8 點開賣

**③ 海瑞摃丸｜貢丸的祖師爺**
- 1948 年從南門市場麵攤起家，據說新竹一半的貢丸業者都出自海瑞門下
- 總店冰櫃有二十多種口味 → **「怪口味貢丸挑戰」**橋段
- 以門市販售為主，拍攝前先確認現場能不能試吃 / 內用

**④ 阿城號米粉｜城隍廟老字號**
- 米粉選用新竹南勢一帶的手工米粉
- 城隍廟環境熱鬧，適合拍「廟口小吃」氛圍

**⑤ 柳家肉燥飯｜在地人的青春回憶**
- 招牌其實是肉燥飯，但在地人都會配炒米粉 + 貢丸湯
- 跟阿城號就在附近 → 可以做**「城隍廟米粉 PK」**

**⑥ 東門米粉攤｜壓軸必比登**
- 改用**粗米粉**，跟前面的細米粉形成對比
- 芋頭燉到化開，可以加海鮮、餛飩、松阪豬
- 東門市場文青風、燈光好，適合拍收尾
- ⚠️ 座位少、賣完就收，要預留排隊時間

## 5. 每站拍攝腳本

每一站固定用同一套流程，剪輯時節奏會比較一致：

| 段落 | 長度（成片） | 內容 |
|---|---|---|
| ① 進站 | 10 秒 | 字卡「第 X 站：店名」＋ 招牌空景 ＋ 「剩下 X 站」 |
| ② 店家介紹 | 15 秒 | 旁白講歷史 / 亮點，配店面、菜單、老闆手部特寫 |
| ③ 上菜 | 10 秒 | 慢動作：熱湯冒煙、夾起貢丸、米粉拉起來 |
| ④ 第一口 | 15 秒 | 咬貢丸的聲音（收音要近）＋ 真實反應 |
| ⑤ 評分 | 20 秒 | 每人舉牌打分（見第 6 節） |
| ⑥ 飽足度 | 5 秒 | 「胃容量進度條」動畫更新 |
| ⑦ 一句話總結 | 5 秒 | 「這家適合 ___ 的人」 |

**每站必拍 B-roll：**
- [ ] 店家招牌（正面 + 斜角）
- [ ] 菜單 / 價目表
- [ ] 料理過程（撈湯、炒米粉、灑芹菜）
- [ ] 貢丸切開的剖面特寫（看肉的紋理）
- [ ] 湯匙舀湯
- [ ] 現場人潮 / 環境（避免拍到其他客人正臉）

## 6. 評分系統

每人每站打分，滿分 10 分：

| 項目 | 比重 | 看什麼 |
|---|---|---|
| 🍢 貢丸 Q 彈度 | 30% | 彈性、脆度、肉汁、肉味 |
| 🥣 湯頭 | 20% | 清甜度、鹹度、有沒有喝完的衝動 |
| 🍜 米粉 | 30% | 口感、香氣、醬汁 / 湯的搭配 |
| 💰 CP 值 | 10% | 價格與份量 |
| 🔁 回訪指數 | 10% | 「會不會專程再來？」 |

**特別獎（結尾頒發）：**
- 🏆 總冠軍補給站
- 💪 最 Q 彈貢丸獎
- 🍜 最佳米粉獎
- 🤯 最意外獎（例如：海瑞的怪口味）
- 😵 撞牆獎（吃到哪一站最痛苦）

> 評分完全以出鏡者個人口味為準，影片中說明「純屬個人主觀」，避免引起店家誤會。

## 12. 注意事項

### 🤝 店家禮儀
- 拍攝前**先跟老闆打招呼、徵求同意**，說明是 YouTube / 社群美食影片
- 避開尖峰時段，不要佔用座位太久，拍完就讓位
- 不要擋到動線或廚房
- 拍製作過程（石家、海瑞）**一定要事先問**
- 不拍其他客人的正臉，如果拍到後製要打馬賽克
- 評分以個人口味為主，避免使用貶低店家的字眼

### 🍽️ 吃的策略
- 六家吃下來份量很可觀：**每站點一份大家分**，主持人吃到「能評分」就好
- 前面幾站少喝湯，留胃給後面
- 中場安排散步休息，城隍廟到東門市場之間至少休息 2 小時
- 吃不完打包帶走，不要浪費食物

### 🎬 拍攝
- 老店燈光暗、湯會起霧 → 補光燈打側邊，鏡頭別對著蒸氣
- 店內吵 → 無線麥克風要夾近，關鍵台詞可以拍完後在店外補錄
- 每站拍完立刻記下評分和印象，晚上剪輯才不會忘
